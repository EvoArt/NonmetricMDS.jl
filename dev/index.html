NonmetricMDS.jl

NonmetricMDS.jl finds a low-dimensional representation of observations from their pairwise dissimilarities. nmds uses monotone regression with SMACOF to preserve the order of dissimilarities; pcoa provides a metric principal coordinates ordination. The input must be a square, symmetric matrix with non-negative entries. Row and column i refer to the same observation.

From dissimilarities to an ordination

The matrix below contains distances between five points. Use nmds to place them in two dimensions:

using NonmetricMDS, Random

D = [0.0 1.0 1.0 sqrt(2) 2.0;
     1.0 0.0 sqrt(2) 1.0 1.0;
     1.0 sqrt(2) 0.0 1.0 sqrt(5);
     sqrt(2) 1.0 1.0 0.0 sqrt(2);
     2.0 1.0 sqrt(5) sqrt(2) 0.0]

result = nmds(D; k=2, tries=10, rng=MersenneTwister(42))
result.points   # five rows, two coordinate columns
result.stress   # Kruskal's stress-1; lower means a closer fit

tries controls the number of starts. The first uses a PCoA solution and the others use random configurations. The returned NMDSResult also records whether the best start converged, its iteration count, and how many starts reached a similar solution. For metric principal coordinates instead, call pcoa(D; k=2) and inspect its points, eigenvalues, and explained fields.

Shepard plot

shepard returns the original dissimilarities, distances in the ordination, and the fitted monotone values, sorted by dissimilarity. For example, with the optional Plots.jl package installed:

using Plots

s = shepard(result)
scatter(s.dissimilarity, s.distance;
        xlabel="Dissimilarity", ylabel="Ordination distance",
        label="Pairs", legend=:topleft)
plot!(s.dissimilarity, s.fitted; label="Monotone fit", linewidth=2)

The points show how well the ordination preserves each pairwise dissimilarity; the line shows the fitted monotone relationship. Plots.jl is needed only to draw the figure.

API reference

NonmetricMDS.NonmetricMDS — Module
NonmetricMDS

Ordination of a dissimilarity matrix: non-metric multidimensional scaling (nmds) and principal coordinates analysis (pcoa).

nmds minimises Kruskal's stress-1 by SMACOF majorisation with monotone (isotonic) regression, from several starts, as vegan::metaMDS does with monoMDS. The solution is centred and rotated to its principal axes.

NonmetricMDS.nmds — Function
nmds(D; k=2, tries=20, maxit=500, tol=1e-7, rng=Random.default_rng(),
     labels=String[], threaded=true)

Non-metric multidimensional scaling of the symmetric dissimilarity matrix D in k dimensions.

Each start minimises Kruskal's stress-1 by SMACOF majorisation, refitting a monotone regression of distances on dissimilarities at every step (ties in D are treated by the primary approach, as monoMDS does by default). The first start is the PCoA solution; the others are random. The best solution is centred and rotated to its principal components.

Stress below 0.05 is an excellent representation, below 0.1 good, below 0.2 usable, above 0.2 poor (Kruskal's rule of thumb; Clarke 1993).

Positional forms of earlier versions still work: nmds(D, k) and nmds(D, k, tries).

NonmetricMDS.NMDSResult — Type
NMDSResult

A non-metric MDS solution.

  • points: one row per observation, centred and rotated to principal axes
  • stress: Kruskal's stress-1 of the best solution
  • tries, repeats: number of starts, and how many reached the best solution again (same stress within 1e-4 and Procrustes RMSE < 0.01)
  • converged: whether the best start met the stress tolerance
  • dissimilarities, distances, fitted: per pair (lower triangle, column-major), for a Shepard plot (see shepard)
  • labels: observation names (may be empty)

X, S = nmds(D, 2) still works: iterating gives points then stress.

NonmetricMDS.shepard — Function
shepard(r::NMDSResult)

Data for a Shepard diagram: a named tuple of the original dissimilarities, the ordination distances and the monotone-regression fit, one entry per pair of observations, sorted by dissimilarity.

source
NonmetricMDS.pcoa — Function
pcoa(D; k=2, labels=String[])

Principal coordinates analysis (classical, metric MDS) of the symmetric dissimilarity matrix D, keeping k axes (at most the number of positive eigenvalues). The same as cmdscale(D, k, eig=TRUE) in R, up to the sign of each axis.

source
NonmetricMDS.PCoAResult — Type
PCoAResult

Principal coordinates of a dissimilarity matrix.

  • points: one row per observation, one column per axis kept
  • eigenvalues: all eigenvalues of the double-centred matrix, largest first (negative ones mean the dissimilarity is not Euclidean)
  • explained: share of the total positive eigenvalue sum on each kept axis
  • labels: observation names (may be empty)

NonmetricMDS.procrustes — Function
procrustes(X, Y; scale=true)

Rotate (and, with scale=true, scale) configuration Y to best match X after centring both, as vegan::procrustes(X, Y, symmetric=FALSE). Returns a named tuple (Yrot, rmse, ss): the rotated Y, the root mean squared difference per point, and the residual sum of squares.
